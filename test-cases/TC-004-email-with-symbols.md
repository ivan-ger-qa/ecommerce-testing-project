# TC-004 — Создание пользователя с E-mail, содержащим специальные символы

**Модуль:** Управление пользователями (API)
**Приоритет:** Medium
**Статус:** Failed
**Тип тестирования:** API / Positive

---

## Цель

Проверить возможность создания пользователя с E-mail, содержащим допустимые специальные символы.

---

## Предусловия

* Пользователь авторизован с использованием **Basic Auth**.
* Используются валидные учетные данные Школы Брейни.

---

## Шаги выполнения

### 1. Отправить POST-запрос

```http
POST https://api.brainy.run/go/create_user
```

### 2. Передать E-mail со специальными символами

В поле `email` передать валидный E-mail, содержащий дефис:

```json
{
  "avatar_url": "https://brainy.run/wp-content/uploads/2024/05/candidate2.png",
  "email": "valid-e@mail.ru",
  "name": "Брейни Дефисовый",
  "password": "superpassword",
  "role": "passenger",
  "username": "symbols-email-test"
}
```

### 3. Отправить запрос

Выполнить запрос и проверить HTTP-статус и тело ответа.

---

## Ожидаемый результат

Система успешно создает пользователя.

**HTTP Status:**

```http
201 Created
```

В теле ответа возвращается сообщение об успешном создании пользователя и присвоенный ему идентификатор:

```json
{
  "message": "Пользователь успешно создан",
  "user_id": 123
}
```

---

## Фактический результат

Сервер возвращает HTTP-код `400 Bad Request`.

В ответе сервера возвращается ошибка валидации.

Пользователь не создаётся.

---

## Результат тестирования

| Проверка                       | Ожидаемый результат | Фактический результат | Статус |
| ------------------------------ | ------------------- | --------------------- | ------ |
| Создание пользователя          | `201 Created`       | `400 Bad Request`     | Failed |
| E-mail со специальным символом | E-mail принимается  | Ошибка валидации      | Failed |
| Создание `user_id`             | ID присвоен         | ID не присвоен        | Failed |

**Итог: FAILED**
