# TC-001 — Создание пользователя с ролью `owner`

**Модуль:** Управление пользователями (API)
**Приоритет:** High
**Статус:** Passed
**Тип тестирования:** API / Positive

---

## Цель

Проверить возможность создания нового пользователя с ролью `owner` через API.

---

## Предусловия

* Пользователь авторизован с использованием **Basic Auth**.
* Используются валидные учетные данные Школы Брейни.
* API доступен для отправки запросов.

---

## Шаги выполнения

### 1. Отправить POST-запрос

```http
POST https://api.brainy.run/go/create_user
```

### 2. Передать данные пользователя

В теле запроса передать валидные данные:

```json
{
  "avatar_url": "https://brainy.run/wp-content/uploads/2024/05/candidate2.png",
  "email": "brainyowner@brainy.run",
  "name": "Брейни",
  "password": "superpassword",
  "role": "owner",
  "username": "brainyowner"
}
```

### 3. Отправить запрос

Выполнить запрос и проверить HTTP-статус и тело ответа.

---

## Ожидаемый результат

Система успешно создает пользователя.

**HTTP Status:**

```http
201 Created
```

В теле ответа возвращается сообщение об успешном создании пользователя и присвоенный ему идентификатор:

```json
{
  "message": "Пользователь успешно создан",
  "user_id": 123
}
```

---

## Фактический результат

Получен статус `201 Created`.

Пользователь успешно создан. В ответе возвращается сообщение об успешном создании пользователя и присвоенный `user_id`.

---
