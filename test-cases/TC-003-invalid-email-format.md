# TC-003 — Проверка валидации E-mail при создании пользователя

**Модуль:** Управление пользователями (API)
**Приоритет:** High
**Статус:** Failed
**Тип тестирования:** API / Negative

---

## Цель

Проверить, что API отклоняет запрос на создание пользователя при передаче E-mail, не соответствующего допустимой маске.

---

## Предусловия

* Пользователь авторизован с использованием **Basic Auth**.
* Используются валидные учетные данные Школы Брейни.

---

## Шаги выполнения

### 1. Отправить POST-запрос

```http
POST https://api.brainy.run/go/create_user
```

### 2. Передать некорректный E-mail

В поле `email` передать значение, не соответствующее формату E-mail:

```json
{
  "avatar_url": "https://brainy.run/wp-content/uploads/2024/05/candidate2.png",
  "email": "invalidemail",
  "name": "Брейни",
  "password": "superpassword",
  "role": "passenger",
  "username": "invalidemail-test"
}
```

### 3. Отправить запрос

Выполнить запрос и проверить HTTP-статус и тело ответа.

---

## Ожидаемый результат

Сервер отклоняет запрос с HTTP-кодом `400 Bad Request`.

Ответ сервера:

```json
{
  "message": "Ошибка валидации. Проверьте введенные данные."
}
```

Пользователь не создаётся.

---

## Фактический результат

Сервер возвращает HTTP-код `201 Created`.

Пользователь успешно создаётся с некорректным значением E-mail `invalidemail`.

---

## Результат тестирования

**Status: Failed**

Тест не пройден. API принимает E-mail, не соответствующий допустимому формату, и позволяет создать пользователя.

---

## Обнаруженный дефект

**Название:** API позволяет создать пользователя с некорректным форматом E-mail
