# TC-005 — Проверка валидации логина со смайликами

**Модуль:** Управление пользователями (API)
**Приоритет:** Medium
**Статус:** Failed
**Тип тестирования:** API / Negative

---

## Цель

Проверить, что API корректно обрабатывает попытку создания пользователя с использованием смайликов в поле `username`.

---

## Предусловия

* Пользователь авторизован с использованием **Basic Auth**.
* Используются валидные учетные данные Школы Брейни.

---

## Шаги выполнения

### 1. Отправить POST-запрос

```http
POST https://api.brainy.run/go/create_user
```

### 2. Передать смайлики в поле `username`

```json
{
  "avatar_url": "https://brainy.run/wp-content/uploads/2024/05/candidate2.png",
  "email": "latin-test-emojis@brainy.run",
  "name": "Брейни",
  "password": "superpassword",
  "role": "employee",
  "username": "us👹er"
}
```

### 3. Отправить запрос

Выполнить запрос и проверить HTTP-статус и тело ответа.

---

## Ожидаемый результат

Сервер отклоняет запрос с HTTP-кодом `400 Bad Request`.

Ответ сервера:

```json
{
  "message": "Ошибка валидации. Проверьте введенные данные."
}
```

Пользователь не создаётся.

---

## Фактический результат

Сервер возвращает HTTP-код `500 Internal Server Error`.

Запрос приводит к внутренней ошибке сервера.

Пользователь не создаётся.

---

## Результат тестирования

| Проверка                           | Ожидаемый результат    | Фактический результат       | Статус |
| ---------------------------------- | ---------------------- | --------------------------- | ------ |
| Обработка `username` со смайликами | `400 Bad Request`      | `500 Internal Server Error` | Failed |
| Валидация значения `username`      | Ошибка валидации       | Внутренняя ошибка сервера   | Failed |
| Создание пользователя              | Пользователь не создан | Пользователь не создан      | Passed |

**Итог: FAILED**

---
