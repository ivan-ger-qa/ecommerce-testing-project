# BUG-003 — Успешное создание корпорации с логотипом в неподдерживаемом формате `.webp`

**Модуль:** Управление корпорациями (API)
**Severity:** Low
**Priority:** Low
**Status:** Open

---

## Окружение

**Server:** `api.brainy.run/go`
**Endpoint:** `POST /create_corporation`

---

## Предусловия

* Пользователь авторизован с использованием **Basic Auth**.
* Используются валидные учетные данные Школы Брейни.

---

## Шаги воспроизведения

### 1. Отправить POST-запрос

```http id="g3p8hv"
POST https://api.brainy.run/go/create_corporation
```

### 2. Передать ссылку на изображение в формате `.webp`

В поле `logo_url` передать URL изображения с расширением `.webp`:

```json id="1j2v5z"
{
  "description": "Ешь свои фрукты, Спортакус. Мы уже победили!",
  "logo_url": "https://dsgners.ru/_imgs/2500x2000/files/blog_posts/5779/hypertext/10_1/media-1b0ad89a4a5ad233f5708e21b5998d6638cb07929_1720774515.webp",
  "name": "Ivan GPG",
  "owner_id": 310
}
```

### 3. Отправить запрос

Проверить HTTP-статус и тело ответа.

---

## Ожидаемый результат

Система должна отклонить запрос с HTTP-кодом `400 Bad Request`, поскольку формат изображения `.webp` не поддерживается.

Ожидаемое тело ответа:

```json id="o2k5d7"
{
  "message": "Аватар корпорации не прошел валидацию"
}
```

Корпорация не должна быть создана.

---

## Фактический результат

Система игнорирует формат изображения и успешно создаёт корпорацию.

Сервер возвращает HTTP-код `201 Created`.

Фактическое тело ответа:

```json id="m6b7pd"
{
  "corporation_id": 5257,
  "message": "Корпорация успешно создана"
}
```

---

## Результат

Валидация формата изображения работает некорректно. API принимает ссылку на изображение в формате `.webp`, несмотря на ожидаемое ограничение формата.

Корпорация успешно создаётся с логотипом в неподдерживаемом формате.

**Status:** Open
