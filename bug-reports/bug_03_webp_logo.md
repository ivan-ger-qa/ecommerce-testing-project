[API] Ошибка валидации формата: успешное создание корпорации с логотипом .webp
ID: BUG-003
Серьезность (Severity): Low

Окружение
Адрес сервера: api.brainy.run/go

Предусловия
Пользователь авторизован со своими данными Школы Брейни с помощью Basic Auth.

Шаги воспроизведения
Отправить POST запрос на эндпоинт /create_corporation.

В теле запроса в графе logo_url передать ссылку на изображение в неподдерживаемом формате (например, .webp).
Пример тела запроса:

{
  "description": "Ешь свои фрукты, Спортакус. Мы уже победили!",
  "logo_url": "https://dsgners.ru/_imgs/2500x2000/files/blog_posts/5779/hypertext/10_1/media-1b0ad89a4a5ad233f5708e21b5998d6638cb07929_1720774515.webp",
  "name": "Ivan GPG",
  "owner_id": 310
}

Ожидаемый результат
Система выдаст ошибку 400 Bad Request (Ошибка валидации) и не создаст корпорацию, так как формат файла не поддерживается.
Ожидаемое тело ответа:

{
  "message": "Аватар корпорации не прошел валидацию"
}

Фактический результат
Формат игнорируется системой проверки. Корпорация успешно создана, система возвращает код 201 Created.
Фактическое тело ответа:

{
  "corporation_id": 5257,
  "message": "Корпорация успешно создана"
}
