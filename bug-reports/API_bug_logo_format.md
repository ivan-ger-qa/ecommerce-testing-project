# [API] Ошибка валидации формата: успешная загрузка логотипа в формате .webp

**ID:** BUG-03
**Серьезность (Severity):** Low
**Приоритет (Priority):** Low

## Окружение
- **Адрес сервера:** `api.brainy.run/go`
- **Метод:** POST
- **Эндпоинт:** `/create_corporation`

## Предусловия
Пользователь авторизован со своими данными (Школа Брейни) с помощью Basic Auth.

## Шаги воспроизведения
1. Отправить POST-запрос на создание корпорации (`/create_corporation`).
2. В теле запроса в параметре `logo_url` передать ссылку на изображение в формате `.webp`:json
{
  "description": "Ешь свои фрукты, Спортакус. Мы уже победили!",
  "logo_url": "[https://dsgners.ru/.../media_1720774515.webp](https://dsgners.ru/.../media_1720774515.webp)",
  "name": "Ivan GPG",
  "owner_id": 310
}

Ожидаемый результат
Система отклоняет неподдерживаемый формат, возвращает статус-код 400 Bad Request и не создает корпорацию. Ожидаемое тело ответа:
{
  "message": "Аватар корпорации не прошел валидацию"
}

Фактический результат
Формат .webp пропускается системой. Корпорация успешно создана, возвращается статус-код 201 Created:
{
  "corporation_id": 5257,
  "message": "Корпорация успешно создана"
}
