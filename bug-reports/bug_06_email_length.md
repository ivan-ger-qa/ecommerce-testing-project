# BUG-006 — Ошибка валидации при создании пользователя с E-mail длиной 99–100 символов

**Модуль:** Управление пользователями (API)
**Severity:** Medium
**Priority:** Medium
**Status:** Open

---

## Окружение

**Server:** `api.brainy.run/go`
**Endpoint:** `POST /create_user`

---

## Предусловия

* Пользователь авторизован с использованием **Basic Auth**.
* Используются валидные учетные данные Школы Брейни.

---

## Шаги воспроизведения

### 1. Отправить POST-запрос

```http
POST https://api.brainy.run/go/create_user
```

### 2. Передать E-mail длиной 99–100 символов

В поле `email` передать валидный по формату E-mail, длина которого составляет 99 или 100 символов:

```json
{
  "email": "asdswdasdsadasaaasadasdsadasd2111dddfffffffffffffffasxcxzcfasdasdasdqaweqweqeqweqweqwebc@brainy.run",
  "name": "Брейни",
  "password": "superpassword",
  "role": "abrakadabra",
  "username": "longvalidemailuser"
}
```

### 3. Отправить запрос

Проверить HTTP-статус и тело ответа.

---

## Ожидаемый результат

Система принимает E-mail допустимой длины и успешно создаёт пользователя.

Сервер возвращает HTTP-код `201 Created`.

Ожидаемое тело ответа:

```json
{
  "message": "Пользователь успешно создан",
  "user_id": 3
}
```

---

## Фактический результат

Пользователь не создаётся.

Система возвращает HTTP-код `400 Bad Request`.

Фактическое тело ответа:

```json
{
  "message": "Ошибка валидации. Проверьте введенные данные"
}
```

---

## Результат

API отклоняет валидный по формату E-mail длиной 99–100 символов.

Граничное значение длины E-mail обрабатывается некорректно, в результате чего создание пользователя невозможно.

**Status:** Open
