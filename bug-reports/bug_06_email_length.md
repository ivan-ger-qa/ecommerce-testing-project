[API] Ошибка валидации (400) при вводе email длиной 99-100 символов (Граничные значения)
ID: BUG-006
Серьезность (Severity): Medium

Окружение
Адрес сервера: api.brainy.run/go

Эндпоинт: /create_user

Предусловия
Пользователь авторизован со своими данными Школы Брейни с помощью Basic Auth.

Шаги воспроизведения
Отправить POST запрос на эндпоинт /create_user.

В теле запроса в графе email передать валидный по формату адрес, длина которого составляет 99 или 100 символов.
Пример тела запроса:

{
  "email": "asdswdasdsadasaaasadasdsadasd2111dddfffffffffffffffasxcxzcfasdasdasdqaweqweqeqweqweqwebc@brainy.run",
  "name": "Брейни",
  "password": "superpassword",
  "role": "abrakadabra",
  "username": "longvalidemailuser"
}

Ожидаемый результат
Система успешно обрабатывает email допустимой длины и создает пользователя. Возвращается код 201 Created.
Ожидаемое тело ответа:

{
  "message": "Пользователь успешно создан",
  "user_id": 3
}

Фактический результат
Пользователь не создается, система выдает ошибку валидации 400 Bad Request.
Фактическое тело ответа:

{
  "message": "Ошибка валидации. Проверьте введенные данные"
}
