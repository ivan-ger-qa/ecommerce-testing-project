[API] Ошибка валидации: создание корпорации со спецсимволами в названии
ID: BUG-01
Серьезность (Severity): Medium
Приоритет (Priority): Medium

Окружение
Адрес сервера: api.brainy.run/go

Метод: POST

Эндпоинт: /create_corporation

Предусловия
Пользователь авторизован со своими данными (Школа Брейни) с помощью Basic Auth.

Шаги воспроизведения
Отправить POST-запрос на создание корпорации (/create_corporation).

В теле запроса в параметре name передать значение со спецсимволом (например, дефис -):json
{
"description": "Ешь свои фрукты, Спортакус. Мы уже победили!",
"logo_url": "https://s3.ru1.storage.beget.cloud/bb4e0f3f0f81-brainy-platform/API%2FGO%2Frobbie.jpg",
"name": "ivan-defis",
"owner_id": 310
}

Ожидаемый результат
Система возвращает статус-код `400 Bad Request` (Ошибка валидации) и не создает корпорацию. Ожидаемое тело ответа:

{
  "message": "Имя корпорации не прошло валидацию"
}

Фактический результат
Корпорация успешно создана, система возвращает статус-код 201 Created. Фактическое тело ответа:
JSON
{
  "corporation_id": 5250,
  "message": "Корпорация успешно создана"
}
