# BUG-001 — Успешное создание корпорации при использовании недопустимых спецсимволов в названии

**Модуль:** Управление корпорациями (API)
**Severity:** Medium
**Priority:** Medium
**Status:** Open

---

## Окружение

**Server:** `api.brainy.run/go`
**Endpoint:** `POST /create_corporation`

---

## Предусловия

* Пользователь авторизован с использованием **Basic Auth**.
* Используются валидные учетные данные Школы Брейни.

---

## Шаги воспроизведения

### 1. Отправить POST-запрос

```http
POST https://api.brainy.run/go/create_corporation
```

### 2. Передать название корпорации со специальным символом

В поле `name` передать значение, содержащее дефис `-`:

```json
{
  "description": "Ешь свои фрукты, Спортакус. Мы уже победили!",
  "logo_url": "https://s3.ru1.storage.beget.cloud/bb4e0f3f0f81-brainy-platform/API%2FGO%2Frobbie.jpg",
  "name": "ivan-defis",
  "owner_id": 310
}
```

### 3. Отправить запрос

Проверить HTTP-статус и тело ответа.

---

## Ожидаемый результат

Система должна отклонить запрос с HTTP-кодом `400 Bad Request`.

Корпорация не должна быть создана.

Ожидаемое тело ответа:

```json
{
  "message": "Имя корпорации не прошло валидацию"
}
```

---

## Фактический результат

Система успешно создаёт корпорацию и возвращает HTTP-код `201 Created`.

Фактическое тело ответа:

```json
{
  "corporation_id": 5250,
  "message": "Корпорация успешно создана"
}
```

Корпорация создаётся с названием `ivan-defis`, несмотря на наличие недопустимого специального символа.

---

## Результат

API не выполняет ожидаемую валидацию поля `name` и позволяет создать корпорацию с недопустимым символом в названии.

**Status:** Open
