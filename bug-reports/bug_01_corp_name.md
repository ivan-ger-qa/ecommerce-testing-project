[API] Успешное создание корпорации при использовании недопустимых спецсимволов в названии
ID: BUG-001
Серьезность (Severity): Medium

Окружение
Адрес сервера: api.brainy.run/go

Предусловия
Пользователь авторизован со своими данными Школы Брейни с помощью Basic Auth.

Шаги воспроизведения
Отправить POST запрос на эндпоинт /create_corporation.

В теле запроса в графе name ввести спецсимвол (например, дефис -).
Пример тела запроса:json
{
"description": "Ешь свои фрукты, Спортакус. Мы уже победили!",
"logo_url": "https://s3.ru1.storage.beget.cloud/bb4e0f3f0f81-brainy-platform/API%2FGO%2Frobbie.jpg",
"name": "ivan-defis",
"owner_id": 310
}

## Ожидаемый результат
Система выдаст ошибку `400 Bad Request` (Ошибка валидации) и не создаст корпорацию.
Ожидаемое тело ответа:
{
  "message": "Имя корпорации не прошло валидацию"
}

## Фактический результат
Корпорация успешно создана, система возвращает код 201 Created.
Фактическое тело ответа:

{
  "corporation_id": 5250,
  "message": "Корпорация успешно создана"
}
