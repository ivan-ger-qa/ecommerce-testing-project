# [API] Уязвимость бизнес-логики: создание корпорации пользователем со статусом employee/passenger

**ID:** BUG-02
**Серьезность (Severity):** High
**Приоритет (Priority):** High

## Окружение
- **Адрес сервера:** `api.brainy.run/go`
- **Метод:** POST
- **Эндпоинт:** `/create_corporation`

## Предусловия
Пользователь авторизован со своими данными (Школа Брейни) с помощью Basic Auth.

## Шаги воспроизведения
1. Отправить POST-запрос на создание корпорации (`/create_corporation`).
2. В теле запроса в параметре `owner_id` передать ID пользователя, который имеет статус `employee` или `passenger` (например, ID `247`):json
{
  "logo_url": "[https://s3.ru1.storage.beget.cloud/bb4e0f3f0f81-brainy-platform/API%2FGO%2Frobbie.jpg](https://s3.ru1.storage.beget.cloud/bb4e0f3f0f81-brainy-platform/API%2FGO%2Frobbie.jpg)",
  "name": "IvanCorp",
  "owner_id": 247
}
Ожидаемый результат
Система проверяет права доступа, возвращает статус-код 400 Bad Request (или 403 Forbidden) и не создает корпорацию. Ожидаемое тело ответа:
{
  "message": "Ошибка валидации. Проверьте введенные данные."
}
Фактический результат
Проверка прав доступа отсутствует. Корпорация успешно создана на пользователя без соответствующих прав. Система возвращает статус-код 201 Created:
{
  "corporation_id": 5266,
  "message": "Корпорация успешно создана"
}
