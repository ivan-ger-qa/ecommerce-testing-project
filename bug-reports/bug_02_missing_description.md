# BUG-002 — Ошибка 400 при создании корпорации без поля `description`

**Модуль:** Управление корпорациями (API)
**Severity:** Medium
**Priority:** Medium
**Status:** Open

---

## Окружение

**Server:** `api.brainy.run/go`
**Endpoint:** `POST /create_corporation`

---

## Предусловия

* Пользователь авторизован с использованием **Basic Auth**.
* Используются валидные учетные данные Школы Брейни.

---

## Шаги воспроизведения

### 1. Отправить POST-запрос

```http
POST https://api.brainy.run/go/create_corporation
```

### 2. Не передавать поле `description`

В теле запроса отсутствует поле `description`:

```json
{
  "logo_url": "https://s3.ru1.storage.beget.cloud/bb4e0f3f0f81-brainy-platform/API%2FGO%2Frobbie.jpg",
  "name": "ivan-defis",
  "owner_id": 310
}
```

### 3. Отправить запрос

Проверить HTTP-статус и тело ответа.

---

## Ожидаемый результат

Корпорация успешно создаётся без указания описания.

Система возвращает HTTP-код `201 Created`.

Ожидаемое тело ответа:

```json
{
  "corporation_id": 456,
  "message": "Корпорация успешно создана"
}
```

---

## Фактический результат

Корпорация не создаётся.

Система возвращает HTTP-код `400 Bad Request`.

Фактическое тело ответа:

```json
{
  "message": "Отсутствуют обязательные поля"
}
```

---

## Результат

API считает поле `description` обязательным, хотя при создании корпорации описание не должно быть обязательным.

Запрос с валидными остальными данными отклоняется при отсутствии `description`.

**Status:** Open
