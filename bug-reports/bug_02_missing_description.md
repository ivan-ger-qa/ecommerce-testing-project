[API] Ошибка 400 при попытке создать корпорацию без поля description
ID: BUG-002
Серьезность (Severity): Medium

Окружение
Адрес сервера: api.brainy.run/go

Предусловия
Пользователь авторизован со своими данными Школы Брейни с помощью Basic Auth.

Шаги воспроизведения
Отправить POST запрос на эндпоинт /create_corporation.

В теле запроса не передавать поле description (описание корпорации).
Пример тела запроса:
{
  "logo_url": "https://s3.ru1.storage.beget.cloud/bb4e0f3f0f81-brainy-platform/API%2FGO%2Frobbie.jpg",
  "name": "ivan-defis",
  "owner_id": 310
}

Ожидаемый результат
Корпорация успешно создается без описания, система возвращает код 201 Created.
Ожидаемое тело ответа:
{
  "corporation_id": 456,
  "message": "Корпорация успешно создана"
}

Фактический результат
Корпорация не создана, система выдает ошибку 400 Bad Request из-за отсутствия обязательного поля.
Фактическое тело ответа:
{
  "message": "Отсутствуют обязательные поля"
}
