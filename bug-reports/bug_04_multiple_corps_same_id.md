[API] Отсутствие ограничения на создание нескольких корпораций для одного пользователя
ID: BUG-004
Серьезность (Severity): Medium

Окружение
Адрес сервера: api.brainy.run/go

Предусловия
Пользователь авторизован со своими данными Школы Брейни с помощью Basic Auth.

У пользователя (например, с ID 310) уже создана и существует одна корпорация.

Шаги воспроизведения
Отправить повторный POST запрос на эндпоинт /create_corporation.

В теле запроса передать owner_id (ID 310), за которым уже закреплена корпорация.
Пример тела запроса:

{
  "logo_url": "https://s3.ru1.storage.beget.cloud/bb4e0f3f0f81-brainy-platform/API%2FGO%2Frobbie.jpg",
  "name": "ivan-defis",
  "owner_id": 310
}

Ожидаемый результат
Система проверит наличие привязанной корпорации, выдаст ошибку 400 Bad Request (Ошибка валидации) и не создаст вторую корпорацию.
Ожидаемое тело ответа:

{
  "message": "Ошибка валидации. Проверьте введенные данные."
}

Фактический результат
Ограничение бизнес-логики не срабатывает. Корпорация успешно создана, система возвращает код 201 Created.
Фактическое тело ответа:

{
  "corporation_id": 5257,
  "message": "Корпорация успешно создана"
}
