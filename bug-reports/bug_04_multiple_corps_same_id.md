# BUG-004 — Возможность создания нескольких корпораций для одного пользователя

**Модуль:** Управление корпорациями (API)
**Severity:** Medium
**Priority:** Medium
**Status:** Open

---

## Окружение

**Server:** `api.brainy.run/go`
**Endpoint:** `POST /create_corporation`

---

## Предусловия

* Пользователь авторизован с использованием **Basic Auth**.
* Используются валидные учетные данные Школы Брейни.
* У пользователя с `ID 310` уже существует созданная корпорация.
* Пользователь `ID 310` является владельцем существующей корпорации.

---

## Шаги воспроизведения

### 1. Отправить повторный POST-запрос

```http
POST https://api.brainy.run/go/create_corporation
```

### 2. Передать `owner_id` пользователя, у которого уже существует корпорация

```json
{
  "logo_url": "https://s3.ru1.storage.beget.cloud/bb4e0f3f0f81-brainy-platform/API%2FGO%2Frobbie.jpg",
  "name": "ivan-defis",
  "owner_id": 310
}
```

### 3. Отправить запрос

Проверить HTTP-статус и тело ответа.

---

## Ожидаемый результат

Система проверяет наличие уже существующей корпорации у пользователя `ID 310`.

Запрос отклоняется с HTTP-кодом `400 Bad Request`.

Вторая корпорация для этого пользователя не создаётся.

Ожидаемое тело ответа:

```json
{
  "message": "Ошибка валидации. Проверьте введенные данные."
}
```

---

## Фактический результат

Ограничение бизнес-логики не срабатывает.

Система успешно создаёт вторую корпорацию для пользователя `ID 310` и возвращает HTTP-код `201 Created`.

Фактическое тело ответа:

```json
{
  "corporation_id": 5257,
  "message": "Корпорация успешно создана"
}
```

---

## Результат

API позволяет создать несколько корпораций для одного пользователя, несмотря на наличие уже существующей привязанной корпорации.

Не выполняется проверка ограничения на количество корпораций, связанных с одним владельцем.

**Status:** Open
