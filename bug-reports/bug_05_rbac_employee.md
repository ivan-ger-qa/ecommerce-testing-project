API] Нарушение ролевой модели: создание корпорации на пользователя со статусом employee/passenger
ID: BUG-005
Серьезность (Severity): High

Окружение
Адрес сервера: api.brainy.run/go

Предусловия
Пользователь авторизован со своими данными Школы Брейни с помощью Basic Auth.

Шаги воспроизведения
Отправить POST запрос на эндпоинт /create_corporation.

В теле запроса в графе owner_id передать ID пользователя, имеющего статус employee или passenger (например, ID 247).
Пример тела запроса:

{
  "logo_url": "https://s3.ru1.storage.beget.cloud/bb4e0f3f0f81-brainy-platform/API%2FGO%2Frobbie.jpg",
  "name": "ivan-defis",
  "owner_id": 247
}

Ожидаемый результат
Система проверит права доступа (роли), выдаст ошибку 400 Bad Request (Ошибка валидации) и не создаст корпорацию.
Ожидаемое тело ответа:

{
  "message": "Ошибка валидации. Проверьте введенные данные."
}


Фактический результат
Проверка прав доступа отсутствует. Корпорация успешно создана на пользователя без соответствующих прав, система возвращает код 201 Created.
Фактическое тело ответа:

{
  "corporation_id": 5266,
  "message": "Корпорация успешно создана"
}
