# Иван — QA Engineer

## О себе

Junior QA Engineer с практическим опытом тестирования учебных и pet-проектов.

Основные направления — **ручное и API-тестирование**. Работаю с REST API, Postman, Swagger, SQL и PostgreSQL. Умею составлять тестовую документацию, анализировать результаты тестирования и оформлять баг-репорты.

В настоящее время изучаю **автоматизацию тестирования с использованием Playwright и TypeScript**.

## Hard Skills

* **Manual Testing:** функциональное, регрессионное, позитивное и негативное тестирование
* **API Testing:** Postman, REST API, Swagger, JSON, HTTP
* **Database:** SQL, PostgreSQL, JOIN, фильтрация, выборка данных
* **Test Documentation:** тест-кейсы, чек-листы, баг-репорты, тест-планы
* **DevTools:** Chrome DevTools, анализ HTTP-запросов и ответов
* **Network:** Charles Proxy
* **Tools:** Jira, Git
* **Automation:** Playwright, TypeScript — в процессе изучения
